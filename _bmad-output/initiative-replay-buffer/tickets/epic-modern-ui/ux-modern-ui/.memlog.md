- (event) headless create for story 9.1; inputs: epic-modern-ui R1-R6 and Notes, AD-4/15/23, the mockups, both renders, ui-look-render, and the App's XAML (MainWindow, Library, eight settings views, tray menu, Prompts, Overlay)
- (decision) Token keys are Fluent's own brush keys (verified: 55 keys exist in .NET 10's Fluent dictionaries); four App keys with an Rb prefix cover what Fluent lacks. Reason: WPF can't alias keys dynamically, and AD-23 says Gaming overrides Fluent's keys
- (decision) Gaming state colours (hover, pressed, disabled, input, flyout, info-bar backgrounds, success, caution, text-disabled) are derived from the epic palette; subtle fills are translucent muted grey so they lighten any surface
- (decision) The status dot keeps the Overlay's meaning: success while Buffering, record while Recording; the Gaming render's red Buffering dot is not followed
- (decision) The Favourite star uses text-accent and text-secondary, not the hard-coded gold
- (decision) One flat nav pane: Library, a Settings label, then the eight pages under their existing titles; no renames, no icons; Ctrl+Tab cycles the items
- (decision) The status header is a card at the top of the content column; no Save Clip button and no search, since the App has no such commands
- (decision) The Library stays a virtualized list with card-style rows (128x72 thumbnail, length badge), not a grid; the filters sit under the title
- (decision) The settings layout uses section headers plus cards; the General page gets Appearance (the theme picker, a combo box) and Startup and Overlay sections
- (decision) Uppercase under Gaming is a template converter; wording and view models stay sentence case. Menus, check box labels and body text stay sentence case
- (decision) System title bar in both themes: Mica under Fluent, DWM caption colour bg-base under Gaming; no custom chrome
- (decision) The dialog is an owned window: Yes is the accent default; Esc and close answer No
- (decision) The Overlay card uses overlay-card at 90% opacity, with severity text in danger or success; the glyphs keep their fixed brushes
- (assumption) The window size stays 720x440 as story 3 says; open question: grow it to about 960x600
- (assumption) The empty Library message 'No Clips or Recordings yet.' is the one new state; open question for the builder
- (event) spines finalized; renders in renders/ (9 PNGs) from a scratch prototype; reviewer gate skipped (headless)
