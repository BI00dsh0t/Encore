updated: 2026-10-25T20:33

- (requirement) R1 (parent R14): The app lists Windows Output and Input Devices live, with no restart. Devices with the same name are told apart by their parent device. Devices that aren't present are hidden, unless one is already in a Track Layout; then it's shown as unavailable.
- (requirement) R2 (parent R15): A Global Track Layout holds any number of user-named Tracks, each built from any combination of Audio Devices. A device can be in several Tracks, and all Tracks stay in sync. A new layout starts with an "Everything" Track first. Settings warn, without blocking, when a Track may count the same audio twice.
- (requirement) R3 (parent R16): Audio is captured as recorded, with no gain control. A single-device Track matches its device's level, and a mix of several devices never clips; the limiter acts only above full scale (architecture AD-13).
- (requirement) R4 (parent R18, Global part): In the Global Track Layout the user marks Mic Devices and the Tracks that mute affects. The Mic Mute Hotkey silences only Mic Devices, only in those Tracks, and only in what the app records.
- (requirement) R5 (parent R19): A device dropout leaves silence from that device only. Its audio resumes within 2 s of the device returning, with no capture restart. The Overlay stays silent, but the dropout is raised as `warning.raised { code: device-dropout, overlay: false }` and logged.
- (requirement) R6 (parent R30): The Main App shows a live level meter per Track for the layout being viewed, including an unsaved draft. The meters work with nothing being captured, and update at most 20 times a second.
- (requirement) R7 (parent R33, named-Tracks part): A file captured with a multi-Track layout shows the named Tracks, in order, in VLC and DaVinci Resolve, all in sync.
